📥 Descargar Proyecto

Descarga el proyecto de práctica autocontenido para trabajar con PyTest, Vitest, JUnit 5 y Playwright.

📥 Descargar proyecto de práctica (.zip)

El paquete incluye código fuente, pruebas, configuración y una guía propia de ejecución. No contiene credenciales ni archivos generados de tu computador.

📝 Requisitos

  • Python 3.11+ (para tests PyTest de FastAPI y Flask)
  • Node.js 20+ (para Vitest, React y Playwright)
  • JDK 21 + Maven (para tests JUnit de JSP)
  • Navegador Chromium (para Playwright E2E)

🛠 Instrucciones paso a paso

📂Terminal — Tests Python (FastAPI + Flask)
# Después de descargar y extraer guia-testing-qa.zip
cd guia-testing-qa

# Entorno virtual
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

# Ejecutar tests por fases del flujo maestro
pytest tests/unit/ -v              # Fase 1: lógica pura
pytest tests/integration/ -v       # Fase 3: API y SQLite en memoria
pytest tests/ -v                   # Suite Python completa
pytest --cov=services --cov=routers --cov=schemas --cov-report=term-missing
📂Terminal — Tests JavaScript (Vitest, API compatible con Jest)
cd guia-testing-qa
npm ci
npm test
npm run test:coverage
📂Terminal — Tests JUnit 5 (Maven / Spring Boot)
cd guia-testing-qa
mvn test
mvn test jacoco:report
📂Terminal — Playwright E2E
cd guia-testing-qa
$env:FLASK_SECRET_KEY = "<CLAVE_LOCAL_DE_PRUEBA>"
npx playwright install chromium
npm run e2e
npx playwright show-report

📈 Ver cobertura

Cada herramienta produce su propio reporte. Abre los reportes en la raíz del proyecto:

  • Python: pytest --cov=services --cov=routers --cov=schemas --cov-report=html abre htmlcov/index.html.
  • JavaScript: npm run test:coverage genera coverage/index.html.
  • Java: mvn jacoco:report abre target/site/jacoco/index.html.
